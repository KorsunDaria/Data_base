
1. Для каждой (!) страны подсчитать суммарную зарплату работников, трудоустроенных в подразделениях, расположенных в этой стране.

**Вывести:** код страны, суммарная зарплата.
**Сортировать:** код страны, суммарная зарплата по убыванию.

```sql
SELECT c.country_id, COALESCE(SUM(e.salary), 0) AS total_salary
FROM countries c
LEFT JOIN locations l ON l.country_id = c.country_id
LEFT JOIN departments d ON d.location_id = l.location_id
LEFT JOIN employees e ON e.department_id = d.department_id
GROUP BY c.country_id
ORDER BY c.country_id, total_salary DESC;
```

2. Подсчитать количество работников на каждой (!) должности.

**Вывести:** код должности, количество работников.
**Сортировать:** код должности, количество работников.

*Примечание: подсчет нужно провести для всех должностей, в т.ч. и тех, на которых нет ни одного работника. NULL, получаемый для должностей без сотрудников, заменяется на 0 с помощью COALESCE.*

```sql
SELECT j.job_id, COALESCE(COUNT(e.employee_id), 0) AS cnt
FROM jobs j
LEFT JOIN employees e ON e.job_id = j.job_id
GROUP BY j.job_id
ORDER BY j.job_id, cnt;
```

3. Найти все страны, в которых есть отделы без сотрудников.

**Вывести:** название страны.
**Сортировать:** название страны.

```sql
SELECT DISTINCT c.country_name
FROM countries c
JOIN locations l ON l.country_id = c.country_id
JOIN departments d ON d.location_id = l.location_id
WHERE d.department_id NOT IN (
    SELECT department_id FROM employees WHERE department_id IS NOT NULL
)
ORDER BY c.country_name;
```

4. Найти все страны, в которых нет незаполненных отделов.

**Вывести:** название страны.
**Сортировать:** название страны.

```sql
SELECT c.country_name
FROM countries c
WHERE NOT EXISTS (
    SELECT 1
    FROM locations l
    JOIN departments d ON d.location_id = l.location_id
    WHERE l.country_id = c.country_id
      AND d.department_id NOT IN (
          SELECT department_id FROM employees WHERE department_id IS NOT NULL
      )
)
ORDER BY c.country_name;
```

6. Найти все должности, которые не присутствуют в США.

**Вывести:** название должности.
**Сортировать:** название должности.

```sql
SELECT j.job_title
FROM jobs j
WHERE NOT EXISTS (
  SELECT 1
  FROM employees e
  JOIN departments d ON d.department_id = e.department_id
  JOIN locations l ON l.location_id = d.location_id
  WHERE e.job_id = j.job_id AND l.country_id = 'US'
)
ORDER BY j.job_title;
```

7. Для каждой (!) должности подсчитать количество человек, получающих минимальную допустимую зарплату по их должности.

**Вывести:** код должности, количество человек.
**Сортировать:** количество человек, код должности.

```sql
SELECT j.job_id, COALESCE(COUNT(e.employee_id), 0) AS cnt
FROM jobs j
LEFT JOIN employees e ON e.job_id = j.job_id AND e.salary = j.min_salary
GROUP BY j.job_id
ORDER BY cnt, j.job_id;
```

8. Вывести общую зарплату работников, работающих в отделе с наименьшим количеством сотрудников.

**Вывести:** код отдела, суммарная зарплата.
**Сортировать:** код отдела.

```sql
WITH dept_counts AS (
    SELECT d.department_id,
           COUNT(e.employee_id) AS cnt,
           COALESCE(SUM(e.salary), 0) AS total_salary
    FROM departments d
    LEFT JOIN employees e ON e.department_id = d.department_id
    GROUP BY d.department_id
),
min_cnt AS (
    SELECT MIN(cnt) AS min_cnt FROM dept_counts
)
SELECT dc.department_id, dc.total_salary
FROM dept_counts dc, min_cnt m
WHERE dc.cnt = m.min_cnt
ORDER BY dc.department_id;
```

9. Из страны с наибольшим количеством подразделений (департаментов) выбрать работника, у которого в подчинении больше всего человек. Если таких стран несколько, то найти такого работника для каждой из них.

**Вывести:** код работника.
**Сортировать:** код отдела.

```sql
WITH dep_cnt AS (
  SELECT l.country_id, COUNT(*) AS c
  FROM departments d JOIN locations l ON l.location_id = d.location_id
  GROUP BY l.country_id
),
top_countries AS (
  SELECT country_id FROM dep_cnt WHERE c = (SELECT MAX(c) FROM dep_cnt)
),
emp AS (
  SELECT e.employee_id, e.department_id, l.country_id,
         (SELECT COUNT(*) FROM employees s WHERE s.manager_id = e.employee_id) AS subs
  FROM employees e
  JOIN departments d ON d.department_id = e.department_id
  JOIN locations l ON l.location_id = d.location_id
  WHERE l.country_id IN (SELECT country_id FROM top_countries)
)
SELECT employee_id
FROM emp
WHERE subs = (SELECT MAX(subs) FROM emp e2 WHERE e2.country_id = emp.country_id)
ORDER BY department_id;
```
10. Из страны, в которой проживает сотрудник с наименьшим стажем (если таких сотрудников несколько, то рассмотреть страну для каждого из них), выбрать работника, в подчинении которого больше всего человек.

**Вывести:** код работника.
**Сортировать:** код работника.

```sql
WITH min_tenure_emp AS (
    SELECT e.employee_id, e.department_id
    FROM employees e
    WHERE e.hire_date = (SELECT MAX(hire_date) FROM employees)
),
countries_of_min_tenure AS (
    SELECT DISTINCT l.country_id
    FROM min_tenure_emp mte
    JOIN departments d ON mte.department_id = d.department_id
    JOIN locations l ON d.location_id = l.location_id
),
emp_in_countries AS (
    SELECT e.employee_id, l.country_id,
           (SELECT COUNT(*) FROM employees sub WHERE sub.manager_id = e.employee_id) AS subordinate_cnt
    FROM employees e
    JOIN departments d ON e.department_id = d.department_id
    JOIN locations l ON d.location_id = l.location_id
    WHERE l.country_id IN (SELECT country_id FROM countries_of_min_tenure)
),
max_sub_per_country AS (
    SELECT country_id, MAX(subordinate_cnt) AS max_cnt
    FROM emp_in_countries
    GROUP BY country_id
)
SELECT DISTINCT eic.employee_id
FROM emp_in_countries eic
JOIN max_sub_per_country msc
  ON eic.country_id = msc.country_id AND eic.subordinate_cnt = msc.max_cnt
ORDER BY eic.employee_id;
```
