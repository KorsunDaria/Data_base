1. Выбрать все адреса в базе, соответствующие городу "Tokyo"
**Вывести**: адрес.
**Сортировать**: адрес.

```SQL
select street_address
from locations
where city='Tokyo'
order by street_address
```

2. Определить однофамильцев.
**Вывести:** фамилия, количество однофамильцев.
**Сортировать:** количество однофамильцев, фамилия

```SQL
select e.last_name, count(e.last_name)
from employees e
group by e.last_name
having count(e.last_name)>1
order by count(e.last_name), e.last_name
```

3. Для каждой из должностей определить в каких отделах есть сотрудники, ее занимающие.
**Вывести:** код должности, код отдела.
**Сортировать:** код должности, код отдела.

```SQL
select distinct job_id, department_id
from  employees
where department_id is not null
order by job_id, department_id;
```

4. Выбрать работников, которые хотя бы раз меняли должность.
**Вывести:** код работника, дата последней смены работы.
**Сортировать:** код работника

```SQL
select e.employee_id, max(e.end_date)
from job_history e
group by e.employee_id
order by e.employee_id
```

5. Найти сотрудников, которым не назначен менеджер.**Вывести:** код, фамилия, имя.**Сортировать:** код.

```SQL
select e.employee_id, e.last_name, e.first_name
from employees e
where e.manager_id is NULL
order by e.employee_id 
```

6. Определить месяцы между самым первым трудоустроившимся работником и самым последним**Вывести:** Количество месяцев.**Сортировать:** Количество месяцев.

```SQL
select 
EXTRACT(YEAR FROM age(max(e.hire_date),min(e.hire_date))) * 12 
     + EXTRACT(MONTH FROM age(max(e.hire_date),min(e.hire_date))) as month
from employees e
order by month
```

8. Для каждого отдела, в котором более двух сотрудников, определить максимальный оклад среди сотрудников.**Вывести:** код отдела, максимальный оклад.**Сортировать:** оклад, код отдела.

```SQL
select e.department_id, max(e.salary) as max_s
from employees e
group by e.department_id
having count(e.department_id)>2
order by max_s, e.department_id
```

9. Найти трех сотрудников с максимальными окладами, не превышающими медианный.**Вывести:** фамилия, имя, оклад.**Сортировать:** оклад по убыванию, фамилия, имя.

```SQL
select e.last_name, e.first_name, e.salary
from employees e
where e.salary<=

(SELECT PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY salary) AS median_value
FROM employees)

order by e.salary desc, e.last_name, e.first_name
limit 3
```

10. Определить месяц, в котором было трудоустроено больше всего человек.
    **Вывести:** Порядковый номер месяца
    **Сортировать:** Порядковый номер месяца

```SQL
select extract(month from e.hire_date)
from employees e
group by extract(month from e.hire_date)
order by count(*) desc
limit 1

select extract(month from e.hire_date)
from employees e
group by extract(month from e.hire_date)
having count(*) = 

(select max(count(*)) from employees e
group by extract(month from e.hire_date))

order by extract(month from e.hire_date)

WITH counts AS (
  SELECT EXTRACT(MONTH FROM hire_date) AS month_num, COUNT(*) AS cnt
  FROM employees
  GROUP BY month_num
)
SELECT month_num
FROM counts
WHERE cnt = (SELECT MAX(cnt) FROM counts)
ORDER BY month_num;
```
