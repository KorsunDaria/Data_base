

1. Определить суммарную зарплату работников из Великобритании (страна с названием
   “United Kingdom”).
   Вывести: Сумма

```SQL
select sum(salary)
from employees e
join departments d on e.department_id = d.department_id
join locations l on d.location_id = l.location_id
join countries c on l.country_id = c.country_id
where c.country_name = 'United Kingdom'
```

1. Для каждого сотрудника из Канады найти данные о менеджере
   Вывести: фамилию и имя, оклад работника, фамилию и имя, оклад его менеджера
   Сортировать: фамилия, имя работника.

```SQL
select e.last_name, e.first_name, e.salary, m.last_name, m.first_name, m.salary
from employees e
join employees m on e.manager_id = m.employee_id
join departments d on e.department_id = d.department_id 
join locations l on d.location_id = l.location_id
join countries c on c.country_id = l.country_id
where c.country_name='Canada'
order by e.last_name, e.first_name
```

4. Для стран, в которой трудоустроен хотя бы один сотрудник, подсчитать суммарную
   зарплату работников, трудоустроенных в подразделениях, расположенных в этой
   стране.
   Вывести: название страны, сумма зарплат.
   Сортировать: сумма зарплат по убыванию, код страны.

```SQL
select c.country_name, sum(e.salary) as sum_s
from employees e
join departments d on e.department_id = d.department_id 
join locations l on d.location_id = l.location_id
join countries c on c.country_id = l.country_id
group by c.country_name, c.country_id
having count(e.employee_id)>0
order by sum_s desc, c.country_id 
```

5. Определить количество работников из Европы (регион с именем “Europe”).
   Вывести: Количество работников.

```SQL
select count(e.employee_id)
from employees e 
join departments d on e.department_id = d.department_id 
join locations l on d.location_id = l.location_id 
join countries c on c.country_id = l.country_id
join regions r on c.region_id = r.region_id
where r.region_name = 'Europe'
```

9. Определить год, в котором было трудоустроено больше всего человек.
   Вывести: Год.
   Сортировать: Год

```SQL
with count_month as (
    select extract(year from hire_date) as year, count(e.employee_id) as count
    from employees e
    group by extract(year from hire_date)
)
select year
from count_month
where count= (select max(count) from count_month)
order by year
```

11. Найти всех таких сотрудников, менеджер которых трудоустроен в другом отделе.
    Вывести: код сотрудника, название отдела сотрудника, название страны сотрудника, код
    менеджера, название отдела менеджера, название страны менеджера.
    Сортировать: Код работника.

```SQL
select e.employee_id, d.department_name, c.country_name, c.country_id 
from employees e
join employees m on e.manager_id = m.employee_id
join departments d on e.department_id=d.department_id
join locations l on d.location_id = l.location_id 
join countries c on l.country_id = c.country_id
where e.department_id<>m.department_id

order by e.employee_id
```
