
# SQL DQL — 40 заданий с нарастанием сложности

Продолжение серии «Занятие 1–4» на той же схеме (regions → countries → locations → departments → jobs → employees → job_history). Каждый раздел начинается с перечня техник, которые нужно изучить, чтобы решить его задания — от простого к максимально сложному.

---

## Раздел 1. Продвинутые подзапросы и EXISTS/ALL/ANY

**Изучить:** коррелированные подзапросы; `EXISTS` / `NOT EXISTS`; операторы `ANY`/`ALL`/`SOME`; скалярные подзапросы в `SELECT`; несколько CTE в одном запросе (`WITH a AS (...), b AS (...)`).

1. Найти отделы, в которых нет ни одного сотрудника с зарплатой выше 10000 (`NOT EXISTS`).
   **Вывести:** код отдела, название отдела. **Сортировать:** код отдела.
2. Для каждого сотрудника вывести его зарплату и среднюю зарплату по его должности (скалярный подзапрос).
   **Вывести:** код сотрудника, фамилия, зарплата, средняя зарплата по должности. **Сортировать:** код сотрудника.
3. Найти сотрудников, чья зарплата выше зарплаты любого сотрудника отдела «Shipping» (`ANY`), но ниже зарплаты всех сотрудников отдела «Executive» (`ALL`).
   **Вывести:** код, фамилия, зарплата. **Сортировать:** зарплата.
4. С помощью двух CTE найти отдел с максимальной суммарной зарплатой и вывести всех его сотрудников.
   **Вывести:** код сотрудника, фамилия, зарплата. **Сортировать:** зарплата по убыванию.
5. Найти страны, в которых представлены сотрудники всех должностей, существующих в компании (деление отношений через `NOT EXISTS`).
   **Вывести:** название страны. **Сортировать:** название страны.

## Раздел 2. Самосоединения и иерархии

**Изучить:** `self join` (таблица соединяется сама с собой через разные алиасы); работа со связью `employees.manager_id → employees.employee_id`; агрегация поверх self-join.

1. Найти пары сотрудников одного отдела с одинаковой должностью (без пары «сам с собой», без дублей A-B/B-A).
   **Вывести:** фамилия1, фамилия2, код отдела. **Сортировать:** код отдела, фамилия1.
2. Для каждого менеджера посчитать количество непосредственных подчинённых.
   **Вывести:** код менеджера, фамилия, количество подчинённых. **Сортировать:** количество подчинённых по убыванию.
3. Найти сотрудников, чья зарплата выше зарплаты их непосредственного менеджера.
   **Вывести:** фамилия сотрудника, зарплата, фамилия менеджера, зарплата менеджера. **Сортировать:** фамилия сотрудника.
4. Найти пары «коллег» — сотрудников одного отдела, нанятых в один и тот же год.
   **Вывести:** фамилия1, фамилия2, отдел, год. **Сортировать:** год, отдел.
5. Для каждого сотрудника найти «соседа по зарплате» — сотрудника того же отдела с ближайшим (но не равным) значением зарплаты.
   **Вывести:** код сотрудника, зарплата, код соседа, зарплата соседа. **Сортировать:** код сотрудника.

## Раздел 3. Оконные функции: ранжирование

**Изучить:** `OVER (PARTITION BY ... ORDER BY ...)`; `ROW_NUMBER`, `RANK`, `DENSE_RANK`, `NTILE`; отличие ранжирующих функций друг от друга при повторах значений.

1. Пронумеровать всех сотрудников по убыванию зарплаты в рамках всей компании (`ROW_NUMBER`).
   **Вывести:** номер, фамилия, зарплата. **Сортировать:** номер.
2. Для каждого отдела определить ранг сотрудника по зарплате внутри отдела, с учётом повторов (`RANK`).
   **Вывести:** код отдела, фамилия, зарплата, ранг. **Сортировать:** код отдела, ранг.
3. Найти двух самых высокооплачиваемых сотрудников в каждом отделе (`DENSE_RANK` + фильтрация через CTE).
   **Вывести:** код отдела, фамилия, зарплата. **Сортировать:** код отдела, зарплата по убыванию.
4. Разбить всех сотрудников на 4 квартиля по зарплате (`NTILE(4)`).
   **Вывести:** код сотрудника, зарплата, номер квартиля. **Сортировать:** номер квартиля, зарплата.
5. Для каждой должности найти сотрудника с медианной зарплатой (через `ROW_NUMBER`/`COUNT` или `PERCENT_RANK`).
   **Вывести:** код должности, код сотрудника, зарплата. **Сортировать:** код должности.

## Раздел 4. Оконные функции: агрегация и смещения

**Изучить:** `SUM`/`AVG`/`COUNT` с `OVER (PARTITION BY ... ORDER BY ...)` (накопительные итоги); `LAG`, `LEAD`; `FIRST_VALUE`, `LAST_VALUE`; оконные рамки `ROWS BETWEEN ... AND ...`.

1. Посчитать нарастающий итог зарплат внутри отдела по мере найма сотрудников (running total).
   **Вывести:** код отдела, фамилия, дата найма, зарплата, нарастающий итог. **Сортировать:** код отдела, дата найма.
2. Для каждого сотрудника вывести зарплату следующего по старшинству найма коллеги из того же отдела и разницу с ним (`LEAD`).
   **Вывести:** код сотрудника, зарплата, зарплата следующего, разница. **Сортировать:** код отдела, дата найма.
3. Для каждого отдела определить долю зарплаты каждого сотрудника от суммарной зарплаты отдела.
   **Вывести:** код отдела, фамилия, зарплата, доля (%). **Сортировать:** код отдела, доля по убыванию.
4. Для каждого сотрудника вывести зарплату самого первого нанятого сотрудника его отдела (`FIRST_VALUE`).
   **Вывести:** код отдела, фамилия, зарплата, зарплата первого нанятого. **Сортировать:** код отдела, дата найма.
5. Посчитать скользящее среднее зарплаты по трём предыдущим (по дате найма) сотрудникам того же отдела (`ROWS BETWEEN 2 PRECEDING AND CURRENT ROW`).
   **Вывести:** код отдела, фамилия, дата найма, зарплата, скользящее среднее. **Сортировать:** код отдела, дата найма.

## Раздел 5. Рекурсивные CTE и иерархии

**Изучить:** `WITH RECURSIVE`; базовая и рекурсивная часть запроса; накопление уровня/пути через конкатенацию; защита от циклов.

1. Построить полную цепочку подчинения от президента компании вниз до всех сотрудников с указанием уровня иерархии.
   **Вывести:** код сотрудника, фамилия, уровень. **Сортировать:** уровень, фамилия.
2. Для каждого сотрудника построить путь от него до президента (список фамилий через `→`).
   **Вывести:** код сотрудника, путь. **Сортировать:** код сотрудника.
3. Найти максимальную глубину иерархии в компании.
   **Вывести:** максимальный уровень.
4. Для каждого менеджера посчитать общее число подчинённых, включая подчинённых его подчинённых (рекурсивно).
   **Вывести:** код менеджера, фамилия, общее число подчинённых. **Сортировать:** общее число по убыванию.
5. Найти всех сотрудников не более чем в 2 уровнях подчинения от заданного менеджера.
   **Вывести:** код сотрудника, фамилия, уровень. **Сортировать:** уровень, фамилия.

## Раздел 6. Операции над множествами

**Изучить:** `UNION` / `UNION ALL`; `INTERSECT`; `EXCEPT`; требования к совместимости типов и количеству столбцов; литеральные столбцы-метки для различения источника строки.

1. Получить единый список фамилий и имён всех людей, упомянутых в базе как сотрудник или как менеджер, без дублей.
   **Вывести:** фамилия, имя. **Сортировать:** фамилия.
2. Найти должности, встречающиеся и в отделе «IT», и в отделе «Sales» (`INTERSECT`).
   **Вывести:** код должности. **Сортировать:** код должности.
3. Найти должности, встречающиеся в отделе «Shipping», но никогда не встречавшиеся в отделе «Executive» (`EXCEPT`).
   **Вывести:** код должности. **Сортировать:** код должности.
4. Составить список стран, в которых либо есть сотрудники, либо есть незаполненные отделы, с меткой источника.
   **Вывести:** название страны, источник (`'есть сотрудники'` / `'есть пустые отделы'`). **Сортировать:** название страны.
5. Сравнить множество сотрудников, нанятых до 2005 года, с множеством сотрудников с зарплатой выше средней: вывести тех, кто в обоих множествах, и тех, кто только в одном, с меткой группы.
   **Вывести:** код сотрудника, фамилия, группа. **Сортировать:** группа, фамилия.

## Раздел 7. Комбинированные сложные задачи

**Изучить:** совмещение CTE + оконных функций + join'ов в одном запросе; многоуровневая агрегация (агрегат поверх агрегата).

1. Для каждого отдела найти сотрудника(ов) с максимальной зарплатой, включая случаи с несколькими лидерами (CTE + `RANK`/`DENSE_RANK`).
   **Вывести:** код отдела, фамилия, зарплата. **Сортировать:** код отдела.
2. Определить отдел с наибольшим приростом суммарной зарплаты относительно следующего по рейтингу отдела (CTE + `LAG`/`LEAD`).
   **Вывести:** код отдела, суммарная зарплата, прирост. **Сортировать:** прирост по убыванию.
3. Для каждой страны определить топ-3 самых высокооплачиваемых сотрудника.
   **Вывести:** название страны, фамилия, зарплата. **Сортировать:** название страны, зарплата по убыванию.
4. Найти сотрудников, чья зарплата выросла более чем на 20% при последней смене должности (по `job_history`), и вывести их текущего менеджера.
   **Вывести:** фамилия сотрудника, прирост (%), фамилия менеджера. **Сортировать:** прирост по убыванию.
5. Построить сводку по регионам: количество отделов, количество сотрудников, суммарная и средняя зарплата, доля сотрудников с зарплатой выше средней по компании.
   **Вывести:** название региона, отделов, сотрудников, суммарная зарплата, средняя зарплата, доля (%). **Сортировать:** суммарная зарплата по убыванию.

## Раздел 8. Максимальная сложность

**Изучить:** свободное сочетание всех предыдущих техник — рекурсия + оконные функции + несколько CTE + self-join + многоуровневая агрегация в одном запросе.

1. Для каждого сотрудника с подчинёнными вычислить «ранг эффективности» — отношение его зарплаты к средней зарплате всех его подчинённых по иерархии (рекурсивно); вывести топ-5.
   **Вывести:** код сотрудника, фамилия, ранг эффективности. **Сортировать:** ранг эффективности по убыванию.
2. Найти управленческую цепочку от рядового сотрудника до президента с наибольшим суммарным стажем всех участников цепочки.
   **Вывести:** код сотрудника, суммарный стаж цепочки (лет). **Сортировать:** суммарный стаж по убыванию.
3. Для каждого отдела построить историю по годам: сколько сотрудников нанято, сколько ушло/сменило отдел (по `job_history`), и численность на конец года.
   **Вывести:** код отдела, год, нанято, ушло, численность на конец года. **Сортировать:** код отдела, год.
4. Найти сотрудника(ов), у которых разница между его зарплатой и медианной зарплатой сотрудников на 2 уровня ниже него по иерархии максимальна.
   **Вывести:** код сотрудника, фамилия, разница. **Сортировать:** разница по убыванию.
5. Итоговый отчёт: регион → страна → отдел → менеджер отдела → количество сотрудников → суммарная зарплата → топ-1 сотрудник отдела по зарплате → ранг отдела по суммарной зарплате среди всех отделов.
   **Вывести:** название региона, страны, отдела, фамилия менеджера, количество сотрудников, суммарная зарплата, фамилия топ-сотрудника, ранг отдела. **Сортировать:** ранг отдела.
